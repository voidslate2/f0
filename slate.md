### **Course 1: Mastering Microsoft Copilot Cowork & Scout (Autopilots)**

*Target Audience: Enterprise knowledge workers, power users, and digital transformation leaders looking to adopt next-gen always-on AI assistants.*

* **Chapter 1: Introduction to Autonomous Work:** Distinguishing between standard chat copilots, collaborative Cowork sessions, and always-on "Autopilot" background agents (Microsoft Scout).
* **Chapter 2: Setting up Microsoft Scout:** Configuring local desktop-to-cloud connections, managing the Model Context Protocol (MCP) servers, and tying local filesystems to your enterprise identity.
* **Chapter 3: Deep Dive into Copilot Cowork:** Running multi-threaded workflows, managing shared collaborative sessions, and choosing the right underlying model matched to specific tasks.
* **Chapter 4: Leveraging Work IQ Context:** Understanding how Work IQ maps emails, calendars, chats, and documents into an active enterprise graph to ground your agent's reasoning.
* **Chapter 5: Security, Usage, and Cost Control:** Navigating usage-based Copilot Credits billing, managing tenant governance policies, and utilizing Agent 365 control planes.
* **Chapter 6: Change Management & Adoption:** Building organizational playbooks, publishing curated organization prompts, and scaling safe autonomous workflows across teams.

### **Course 2: Building and Governing Enterprise AI Agents (Microsoft Build)**

*Target Audience: Software developers, architects, and technical leads designing production-grade AI systems.*

* **Chapter 1: The Modern Agentic Stack:** Overview of Microsoft Foundry, Model Context Protocol (MCP), and shifting from monolithic prompts to multi-agent architectures.
* **Chapter 2: Harnessing Microsoft IQ Layers:** Implementing Work IQ, Foundry IQ, and Web IQ APIs to fetch multi-source context dynamically and securely.
* **Chapter 3: Designing Multi-Agent Systems:** Orchestrating task handoffs, memory retention, and persistent state management across distributed agent networks.
* **Chapter 4: Model Diversity & Local Execution:** Utilizing first-party MAI models and configuring local high-performance hardware/VMs (like Azure Cobalt and RTX-backed environments) for edge AI.
* **Chapter 5: Enterprise Governance & Observability:** Implementing tracking, prompt auditing, and compliance safeguards via Microsoft Purview, Entra, and Defender extensions.
* **Chapter 6: Deployment & CI/CD for Agents:** Pushing prototypes into enterprise production environments, managing version control, and configuring continuous monitoring.

### **Course 3: Advanced Data Engineering & Analytics with Microsoft Fabric (FabCon)**

*Target Audience: Data engineers, BI professionals, and database administrators modernizing data estates.*

* **Chapter 1: Modernizing with Fabric Runtime 2.0:** Leveraging Apache Spark 4.0, Python 3.12, and Delta Lake 4.0 enhancements for high-speed data processing.
* **Chapter 2: Zero-Copy Architecture & Mirroring:** Expanding OneLake shortcuts to connect external sources like Oracle, SAP Datasphere, and MySQL seamlessly.
* **Chapter 3: Centralized Management via Database Hub:** Controlling database workloads, monitoring capacity health, and organizing enterprise data spaces from a single plane.
* **Chapter 4: Natural Language Analytics with Fabric Data Agents:** Deploying and fine-tuning secure data agents that translate plain English into optimized queries over lakehouses and warehouses.
* **Chapter 5: CI/CD Pipelines & Fabric CLI v1.5:** Implementing native command-line operations to automate workspace deployments using GitHub Actions and Azure DevOps.
* **Chapter 6: Data Governance & Security Operations:** Enforcing Purview sensitivity labels, managing row/column-level security, and optimizing storage cost thresholds in OneLake.
